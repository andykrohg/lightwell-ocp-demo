Pipeline Architecture

git-clone ──→ maven-build ──→ buildah ──┬──→ cosign-sign ──────┐
                   │                    ├──→ acs-image-check ──┤──→ deploy

                   └──→ upload-sbom-to-tpa (parallel)

The same Tekton pipeline runs for both builds. The vulnerable build uses --soft-fail on ACS checks so it deploys despite violations — letting you compare both side by side.
