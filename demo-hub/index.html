Act 2 — The Fix
3

Lightwell Network: Drop-In Remediated Dependencies

Lightwell provides the same dependency versions with backported security patches. No code changes, no API breaks — just a different Maven repository. The version suffix .rhlw-NNNNN indicates a patched build.

Lightwell also publishes VEX (Vulnerability Exploitability eXchange) data for its remediated packages. VEX tells downstream tooling: "this CVE has been resolved in this build — the vulnerable code is not present."

Compare VEX Check Results

The remediated build runs the same pipeline. This time, Lightwell's VEX data is applied during the pipeline vex-check step. The CVEs covered by VEX are suppressed — they're confirmed as patched in the .rhlw builds.

What to show In the pipeline run logs, find the vex-check step. Compare the summary line: Total vulnerabilities → Suppressed by VEX → Remaining. The Lightwell-covered CVEs are suppressed, leaving only unrelated findings. Note: TPA tracks the SBOM for provenance but doesn't apply VEX to its own CVE view — the suppression is only visible in the pipeline logs.

Act 3 — Lock the Door
6

Enable VEX Enforcement

Now that a clean alternative exists, require that builds include verified VEX remediation data. Builds that ship unvetted dependencies — with zero VEX suppressions — are blocked. This is the shift from "detect" to "prevent."

What to show The pipeline is re-triggered with REQUIRE_VEX=true. Since the vulnerable build's dependencies don't match any VEX statements, zero CVEs are suppressed — and the vex-check step fails the build.
OpenShift — Pipeline Runs
7

The Full Supply Chain

With VEX enforcement in the pipeline and cosign image signing on every build, the supply chain is locked down:

  1. Pipeline vex-check — blocks builds without verified remediation data
  2. Cosign signing — only pipeline-built images are trusted
  3. ACS — monitors CVEs across deployments and enforces image signature verification
  4. TPA — tracks every SBOM and advisory for full supply chain visibility

Key Takeaways

  • Drop-in replacement — no code changes, no version upgrades
  • Critical CVEs eliminated at the dependency level by Lightwell Network
  • VEX data enables accurate vulnerability assessment, distinguishing patched from unpatched
  • Pipeline enforcement blocks builds with unresolved vulnerabilities
  • Image signing with Sigstore/cosign for supply chain integrity
  • Full SBOM visibility tracked and analyzed in Trusted Profile Analyzer
  • SLSA Level 3 build provenance for all Lightwell artifacts
